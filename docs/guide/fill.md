# 智能填充

填充柄位于选区右下角（7×7 像素，悬停显示十字光标）。拖动它即可把源区域的内容沿四个方向延伸——**向上 / 向左拖动会反向延续序列**，和 Excel 行为一致。填充是可撤销的（`FillRangeCommand`）。

## 序列识别规则

引擎（`src/fill/series.ts`）对源区域依次尝试以下模式，命中即生成序列：

### 数字

- **等差源**精确延续：`1, 3, 5` → `7, 9, 11`。
- **非等差源**用最小二乘趋势线外推（与 Excel 的 TREND 机制相同）：`1, 2, 4` → 按趋势继续。
- **单独一个数字**默认不是序列，直接复制；按住 Ctrl 拖动则变为递增（见下文 Ctrl 行为）。
- 输出对浮点误差做了 `1e10` 精度圆整。

### 日期

识别 `yyyy-mm-dd`、`yyyy/m/d`、`yyyy.m.d` 三种写法。步长取源区域的平均天数间隔（单日期默认 +1 天），输出保留锚点单元格的分隔符和补零风格。

### 星期 / 月份列表（中英文）

内置循环列表（换行循环，Sun→Mon 记 +1 步）：

| 列表 | 内容 |
|------|------|
| 英文星期缩写 / 全称 | Mon…Sun / Monday…Sunday |
| 英文月份缩写 / 全称 | Jan…Dec / January…December |
| 中文星期 | 星期一…星期日 |
| 中文月份 | 一月…十二月 |

### 文本 + 尾随数字

`Item1` → `Item2` → `Item3`；数字延续，保留前导零宽度（`A007` → `A008`）。步长取相邻单元格的差值，否则为 1。

### 都不匹配

回退为**复制**源区域（循环源单元格），并继承样式（`styleId`）和单元格类型。

## Ctrl 键切换（与 Excel 一致）

拖动全程跟踪 Ctrl / ⌘ 键（不只看按下瞬间），效果是**反转默认行为**：

| 源内容 | 直接拖动 | Ctrl + 拖动 |
|--------|----------|-------------|
| 可成序列（`1,2`、日期、星期…） | 生成序列 | 复制 |
| 单个普通数字 | 复制 | 递增（+1、+2…） |
| 纯文本 | 复制 | 复制 |

## 公式与样式

- 填充公式单元格时，引用会随位置平移：`shiftFormula(formula, dr, dc)` 按 Excel 语义移动单元格引用，并**尊重 `$` 绝对锚定**（`$A$1` 不动、`$A1` 只锁列、`A$1` 只锁行）。
- 新生成的单元格继承源单元格的样式与类型。

## 方向判定

按拖动的位移轴向判定填充方向（水平拖过竖长选区仍然水平填充）；`normalizeFillTarget` 会把源区域和拖拽目标合并成完整的填充范围。

## 程序化触发

填充由渲染器内部的 `FillHandle` 处理鼠标事件（该类未从包根导出），应用层一般无需直接调用。若想以命令方式触发同样的填充效果，可执行 `FillRangeCommand`（内部命令，UI 已自动接线）。
