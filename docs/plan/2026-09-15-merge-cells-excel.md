# 合并单元格 — Excel 全对齐实施计划

日期：2026-09-15
状态：已完成（2026-09-15）

## 一、现状盘点（已完成 vs 缺口）

已有基础设施：

- 数据层：`SheetData.merges`、`Store.addMerge/removeMerge/getMergeAt`、快照序列化、`merge` 事件。
- 命令：`SetMerge`（可撤销）。
- 渲染：跳过非锚点单元格、锚点跨区绘制文本、`mergedPaintStyle`、合并区禁文本溢出。
- 菜单：格式菜单「合并单元格 / 取消合并」。

与 Excel 对齐的缺口（本次要补的）：

| # | 领域 | Excel 行为 | 现状 |
|---|------|-----------|------|
| 1 | 合并语义 | 多格有值时只保留左上值，弹提示「合并单元格时，仅保留左上角的值，而放弃其他值」 | 直接合并，非锚点值不清除、无提示 |
| 2 | 工具入口 | 开始工具栏「合并后居中」下拉：合并后居中 / 跨越合并 / 合并单元格 / 取消合并 | 仅格式菜单两项 |
| 3 | 跨越合并 | Merge Across：多行选区按行逐行合并 | 无 |
| 4 | 选区交互 | 点击合并区任意位置选中整个合并区；拖动选区自动吸附合并区边界 | 点击只选中单个格 |
| 5 | 键盘导航 | 方向键/Tab/Enter 跨过合并区整体移动 | 逐格移动，会进合并区内部 |
| 6 | 复制粘贴 | 合并区整体复制；粘贴目标需与源合并结构一致，否则报错「此操作要求合并单元格都具有相同大小」；取消合并后粘贴值平铺 | 无合并处理 |
| 7 | 行/列插删 | 插删行列时合并区整体平移/裁剪；删除穿过合并区则移除该合并 | 不处理，合并串失效漂移 |

| 9 | 排序/筛选 | 选区含合并区时排序报错拒绝 | 未拦截 |
| 10 | 编辑 | F2/双击/输入只作用于锚点；取消合并后值留在锚点 | 基本成立（锚点绘制），需补测试 |
| 11 | F4 重复 | F4 可重复上一次合并/取消合并 | repeat.ts 需确认覆盖 |

## 二、Excel 行为细则（验收基准）

1. **合并（Merge Cells）**：保留左上角单元格的值与格式；其余格值清空。若其余格中存在非空值，先弹确认提示（antd Modal，对齐现有 `confirmNew` 模式），确认后执行；单区域多合并重叠时，合并动作替换选区内已有合并。
2. **合并后居中（Merge & Center）**：合并 + 锚点水平居中；再次点击已居中合并区 = 取消合并（Excel 是 toggle 按钮）。
3. **跨越合并（Merge Across）**：选区每行独立合并为一个合并区；行内有值冲突同样触发提示。
4. **取消合并（Unmerge）**：选区内所有合并区全部拆除，值保留在各自锚点格。
5. **选区吸附**：mousedown 落在合并区内 → 选区扩展为整个合并区；shift/拖动扩展选区时边缘吸附合并区外边界。
6. **键盘导航**：方向键从合并区移出时跳到合并区外相邻格；从格外移入时落到锚点所在的合并区整体。Tab/Enter 同理按可见行/列步进。
7. **复制**：源选区含合并区时记录合并结构；**粘贴**：
   - 目标无合并且尺寸匹配 → 复刻合并结构；
   - 目标已有合并且结构不完全一致 → 报错弹窗「此操作要求合并单元格都具有相同大小」，不执行；
   - 剪切+粘贴 = 移动（源合并拆除）。
8. **行/列插删**：合并区在插入点之后 → 平移；穿过合并区 → 合并区扩大（插入）或裁剪/移除（删除，删除范围覆盖整个合并区则移除）。
9. **排序/筛选**：选区与任意合并区相交 → 拒绝并提示（Excel：「此操作要求合并单元格都具有相同大小」）。
10. **渲染补充**：合并区背景色/边框按整区绘制；边框沿合并区外沿绘制（内部无网格线）。现有渲染已大部分覆盖，补边框外沿规则。

## 三、实施步骤（按依赖排序）

### 阶段 1：数据层与命令语义
1. `Store` 新增辅助：`getMergeAt` 已有；新增 `expandRangeToMerges(range)`、`mergesIntersecting(range)`、`removeMergesIn(range)`。
2. 重写 `SetMerge`：执行时清除非锚点值（纳入 undo 快照）、替换重叠合并；undo 恢复原值与原合并集。复用 `sheetSnapshot` 的局部快照思路。
3. 新命令 `SetMergeAcross`（逐行合并）。
4. 菜单/工具栏：格式菜单加「合并后居中」「跨越合并」；Toolbar 增加合并下拉按钮（对齐 antd Dropdown.Button 风格）。
5. 值冲突提示：合并前检测非锚点非空值，`Modal.confirm` 提示，取消则不执行。

### 阶段 2：选区与键盘
6. `Selection`/Spreadsheet mousedown：命中合并区 → 选区设为合并区；拖动扩展时吸附。
7. `KeyboardHandler`：方向键/Tab/Enter 步进逻辑感知合并（取目标格所在合并区，跳过内部格）。

### 阶段 3：剪贴板 / 行列插删 / 填充 / 排序
8. `ClipboardService`：复制载荷带合并结构；粘贴按第 7 条规则校验与复刻，失败弹错。
9. `InsertRow/DeleteRow/InsertCol/DeleteCol`：合并区平移/扩大/裁剪/移除，全部纳入 undo。
10. `FillRange`：源含合并区时按比例复刻合并结构到目标。
11. `SortRange`/`SetAutoFilterCriteria`：选区与合并区相交时拒绝并提示。

### 阶段 4：渲染与细节
12. 合并区外沿边框绘制规则；F4 repeat 覆盖新命令；Editor 输入定位到锚点。

### 阶段 5：测试与验证
13. 每个命令补 vitest 单测（合并清值/undo、跨越合并、粘贴校验矩阵、插删行列平移表、排序拒绝）。
14. 渲染测试：合并区边框、吸附后的选区绘制。
15. 三件套全绿：`npx vitest run` + `npx tsc --noEmit` + `npx eslint src/ test/`。
16. dev server 启动 + headless Chrome 截图人工核对。

## 四、不做的事（避免范围蔓延）

- 合并区内跨列文本居中对齐（Center Across Selection，Excel 另一独立功能）。
- 条件格式/迷你图在合并区内的特殊规则。
- 打印/导出 Excel 文件的合并单元格（io 层 xlsx 导出，若需要另立任务）。

## 五、风险

- 插删行列的合并平移矩阵用例多，需穷举测试（插入点在前/穿头/穿中/穿尾/在后 × 行/列）。
- 选区吸附改动影响所有鼠标交互路径，需回归拖动填充、框选、shift 扩展。
