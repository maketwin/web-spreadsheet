# 接口侦察代理（Mock 平台 · 通道③种子）

本地反向代理：把目标站点（默认 `https://www.yunoa.com`）整体映射到本机端口，
你照常登录/操作，代理实时记录页面调用的全部接口（方法/入参/出参/耗时/状态）。
这是 Mock 平台"接管第三方页面"路线的第一步——先看清它调什么，再谈接管。

## 用法

```bash
node proxy/server.mjs                        # 默认上游 yunoa，端口 8787
UPSTREAM=https://www.yunoa.com PORT=8787 node proxy/server.mjs   # 显式配置
```

1. **用 OA**：浏览器打开 <http://127.0.0.1:8787/>，正常登录（会话 Cookie 经代理落在本机），
   然后访问原地址的本地版，例如
   `http://127.0.0.1:8787/oa-inclution/web-excel/excel?id=…&formStatus=disabled`
2. **看流量**：另开 <http://127.0.0.1:8787/__spy/>——实时接口清单，点击条目展开请求/响应体；
   「只看接口」过滤静态资源，「导出 JSON」下载完整清单（配置 mock 规则的原料）。

## 安全边界（有意为之）

- 上游在启动时固定为一个公网 http/https 地址，**拒绝环回/内网/保留段**，
  不接受请求里指定的任意目标——这个进程只能和你配置的那个站点说话。
- 会话 Cookie 只在本机浏览器与本地进程之间流转，不落任何第三方。
- 代理剥离了 CSP / X-Frame-Options 等响应头（本地代理的常规做法，也是后续
  注入记录器的落点）。

## 已知边界

- **SSO 跳到其他域名**时浏览器会离开本地代理；登录完成跳回 yunoa 域的链接需要
  手动把域名换回 `127.0.0.1:8787`（同域族的自动重定向已改写）。
- **WebSocket** 暂未代理（侦察阶段多数 OA 走 HTTP；需要时再加）。
- 响应体超过 256KB 截断存储；页面资源类请求只计数不存体。
